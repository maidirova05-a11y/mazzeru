# Mazzeru — сайт-портфолио

Стиль BOLD: Warm White `#FAF8F2`, Cobalt Blue `#0047FF`, Acid Yellow `#E7FF00`; шрифты Unbounded (логотип) и Inter Tight.
При первом заходе за сессию показывается интро с ZZ-знаком (клик — пропустить).

Статичный сайт (HTML + CSS + JS), без сборки. 4 страницы:

| Файл | Страница |
|---|---|
| `index.html` | Главная: все проекты с фильтром, цель, стратегия, команда, FAQ, контакты |
| `ai-content.html` | ИИ контент / Love Story |
| `mobilography.html` | Мобилография + слайдер «до/после цветокора» |
| `websites.html` | Разработка сайтов и лендингов |

## Языки: KZ / RU / ENG
Переключатель в шапке. Выбор запоминается, а ссылку можно отправить с языком: `index.html?lang=kz`, `?lang=en`.
- Тексты страниц (заголовки, кнопки, пункты) — **`assets/js/i18n.js`**: `"ключ": { ru, kz, en }`.
  Ключ совпадает с атрибутом `data-i18n` в HTML. Русский текст в HTML — запасной вариант.
- Проекты, цены, FAQ, команда — в **`assets/js/data.js`**, каждый текст записан как `tx("RU", "KZ", "EN")`.

## Как редактировать
Почти всё меняется в одном файле — **`assets/js/data.js`**:
- `contacts` — телефон, WhatsApp, Telegram, Instagram, email
- `projects` — проекты (добавить = скопировать блок). Поле `video` — путь к mp4, откроется по клику.
  Кейсы «Сайты» — проекты AZ Group, скриншоты лежат в `assets/img/projects/`
- `team` — основатели: имя, роль, `photo` (фото в `assets/img/team/`, лучше вертикальное 4:5), `instagram` (ник без @). Пятого участника добавить копированием блока
- `packages` — пакеты и цены по каждому направлению
- `faq` — вопросы и ответы

Свои фото и видео кладите в `assets/img/` и `assets/video/`.
Цвета и шрифты задаются в начале `assets/css/style.css`.

## Как посмотреть локально
```
python -m http.server 5500
```
и открыть http://localhost:5500

## Публикация
Сайт опубликован на Vercel: https://mazzeru.vercel.app (проект `mazzeru`).
Обновить после правок — из этой папки:
```
vercel deploy --prod
```
